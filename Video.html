// ══════════════════════════════════════════════════════ // GOOGLE APPS SCRIPT — Quét Vận Đơn (v2: login qua Sheet + phân loại) // Paste toàn bộ code này vào Google Apps Script rồi Deploy lại (New deployment) // ══════════════════════════════════════════════════════ // ⚙️ CẤU HÌNH — đổi các giá trị này const SHEET_ID = '1tvZW1VAesFnp1CzPYle_4jhWdt2WCWPNw3jnu8Hcps8'; // ID của Google Sheet (lấy từ URL) const SHEET_NAME = 'Hoan nhan thuc te'; // Tab lưu vận đơn const ACCOUNTS_SHEET = 'TaiKhoan'; // Tab chứa tài khoản đăng nhập const DRIVE_FOLDER_ID = '1b_I5Xd-oQef4O43ER9Xyp6Tep4X-2wnO'; // Folder ID Google Drive lưu ảnh // ══════════════════════════════════════════════════════ function doPost(e) { try { const data = JSON.parse(e.postData.contents); if (data.action === 'login') return doLogin(data); if (data.action === 'addVanDon') return addVanDon(data); if (data.action === 'findVanDon') return findVanDon(data); if (data.action === 'addVideo') return addVideo(data); return jsonResponse({ status: 'error', message: 'Unknown action' }); } catch (err) { return jsonResponse({ status: 'error', message: err.toString() }); } } function doGet(e) { return jsonResponse({ status: 'ok', message: 'API is running' }); } // ══════════════════════════════════════════════════════ // ĐĂNG NHẬP — đối chiếu với tab TaiKhoan // Cấu trúc tab TaiKhoan (hàng 1 là tiêu đề): // A: TaiKhoan | B: MatKhau | C: TenNhanVien | D: MaNhanVien // ══════════════════════════════════════════════════════ function doLogin(data) { const ss = SpreadsheetApp.openById(SHEET_ID); const sheet = ss.getSheetByName(ACCOUNTS_SHEET); if (!sheet) { return jsonResponse({ status: 'error', message: 'Không tìm thấy tab tài khoản "' + ACCOUNTS_SHEET + '"' }); } const username = String(data.username || '').trim(); const password = String(data.password || '').trim(); if (!username || !password) { return jsonResponse({ status: 'error', message: 'Thiếu tài khoản hoặc mật khẩu' }); } const values = sheet.getDataRange().getValues(); for (let i = 1; i < values.length; i++) { // bỏ hàng tiêu đề const u = String(values[i][0] || '').trim(); const p = String(values[i][1] || '').trim(); if (u && u === username && p === password) { return jsonResponse({ status: 'ok', username: u, nhanVien: values[i][2] || u, maNhanVien: values[i][3] || '' }); } } return jsonResponse({ status: 'error', message: 'Sai tài khoản hoặc mật khẩu' }); } // ══════════════════════════════════════════════════════ // GHI VẬN ĐƠN // Thứ tự cột: A MaVanDon | B ThoiGian | C AnhChup | D NguonHoan // E TinhTrang(Ảo/Không ảo) | F LoaiVanDe // ══════════════════════════════════════════════════════ function addVanDon(data) { const ss = SpreadsheetApp.openById(SHEET_ID); const sheet = ss.getSheetByName(SHEET_NAME); if (!sheet) { const allSheets = ss.getSheets().map(s => s.getName()).join(', '); return jsonResponse({ status: 'error', message: 'Không tìm thấy sheet "' + SHEET_NAME + '". Các sheet có sẵn: ' + allSheets }); } // 1. Upload ảnh lên Google Drive let anhUrl = ''; if (data.anhChup && data.anhChup.startsWith('data:image')) { try { anhUrl = uploadImageToDrive(data.anhChup, data.maVanDon); } catch (err) { anhUrl = 'Upload lỗi: ' + err.toString(); } } // 2. Ghi vào Sheet const thoiGian = new Date(); const row = [ data.maVanDon || '', // A: MaVanDon thoiGian, // B: ThoiGian anhUrl || '', // C: AnhChup (lưu link) data.nguonHoan || '', // D: NguonHoan (Long J&T / Khác) data.tinhTrang || '', // E: TinhTrang (Ảo / Không ảo) data.loaiVanDe || '' // F: LoaiVanDe ]; sheet.appendRow(row); const lastRow = sheet.getLastRow(); sheet.getRange(lastRow, 2).setNumberFormat('dd/mm/yyyy hh:mm:ss'); // cột B ThoiGian return jsonResponse({ status: 'ok', anhUrl: anhUrl, message: 'Đã lưu thành công' }); } // ══════════════════════════════════════════════════════ function uploadImageToDrive(base64Data, maVanDon) { const parts = base64Data.split(','); const mimeType = parts[0].match(/:(.*?);/)[1]; const base64 = parts[1]; const blob = Utilities.newBlob( Utilities.base64Decode(base64), mimeType, (maVanDon || 'VD') + '_' + Date.now() + '.jpg' ); const folder = DriveApp.getFolderById(DRIVE_FOLDER_ID); const file = folder.createFile(blob); file.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW); const fileId = file.getId(); return 'https://drive.google.com/uc?id=' + fileId; } // ══════════════════════════════════════════════════════ // TRA CỨU VẬN ĐƠN theo mã (trả về tất cả lần quét, mới nhất trước) // ══════════════════════════════════════════════════════ function findVanDon(data) { const ss = SpreadsheetApp.openById(SHEET_ID); const sheet = ss.getSheetByName(SHEET_NAME); if (!sheet) { return jsonResponse({ status: 'error', message: 'Không tìm thấy sheet "' + SHEET_NAME + '"' }); } const ma = String(data.maVanDon || '').trim(); if (!ma) return jsonResponse({ status: 'error', message: 'Thiếu mã vận đơn' }); const values = sheet.getDataRange().getValues(); const tz = Session.getScriptTimeZone(); const results = []; for (let i = values.length - 1; i >= 1; i--) { // từ mới nhất, bỏ hàng tiêu đề const rowMa = String(values[i][0] || '').trim(); if (rowMa && rowMa === ma) { const t = values[i][1]; const thoiGian = (t instanceof Date) ? Utilities.formatDate(t, tz, 'dd/MM/yyyy HH:mm:ss') : String(t || ''); results.push({ maVanDon: rowMa, thoiGian: thoiGian, anhUrl: String(values[i][2] || ''), nguonHoan: String(values[i][3] || ''), tinhTrang: String(values[i][4] || ''), loaiVanDe: String(values[i][5] || '') }); } } if (results.length === 0) return jsonResponse({ status: 'notfound', message: 'Chưa có mã ' + ma }); return jsonResponse({ status: 'ok', count: results.length, results: results }); } // ══════════════════════════════════════════════════════ // VIDEO: tim dong theo ma roi ghi link video vao cot J (boc) hoac K (dong) // boc hang -> khop cot A (1); dong hang -> khop cot H (8); ghi J(10)/K(11) function addVideo(data) { const ss = SpreadsheetApp.openById(SHEET_ID); const sheet = ss.getSheetByName(SHEET_NAME); if (!sheet) return jsonResponse({ status: 'error', message: 'Không tìm thấy sheet "' + SHEET_NAME + '"' }); const ma = String(data.maVanDon || '').trim(); if (!ma) return jsonResponse({ status: 'error', message: 'Thiếu mã vận đơn' }); const loai = (data.loai === 'dong') ? 'dong' : 'boc'; const matchCol = (loai === 'dong') ? 7 : 0; // H=index7 / A=index0 const writeCol = (loai === 'dong') ? 11 : 10; // K=11 / J=10 (1-based) const tenCot = (loai === 'dong') ? 'H' : 'A'; const values = sheet.getDataRange().getValues(); let rowIdx = -1; for (let i = values.length - 1; i >= 1; i--) { // mới nhất trước, bỏ tiêu đề if (String(values[i][matchCol] || '').trim() === ma) { rowIdx = i + 1; break; } } if (rowIdx === -1) return jsonResponse({ status: 'notfound', message: 'Không tìm thấy mã ' + ma + ' ở cột ' + tenCot }); let videoUrl = ''; try { videoUrl = uploadVideoToDrive(data.video, ma, loai); } catch (err) { return jsonResponse({ status: 'error', message: 'Upload video lỗi: ' + err.toString() }); } sheet.getRange(rowIdx, writeCol).setValue(videoUrl); return jsonResponse({ status: 'ok', message: 'Đã lưu video', url: videoUrl, row: rowIdx }); } function uploadVideoToDrive(dataUrl, maVanDon, loai) { dataUrl = String(dataUrl || ''); const marker = ';base64,'; const idx = dataUrl.indexOf(marker); if (idx < 0) throw new Error('Video không hợp lệ'); const mimeType = (dataUrl.substring(5, idx).split(';')[0]) || 'video/webm'; const b64 = dataUrl.substring(idx + marker.length); const ext = (mimeType.indexOf('mp4') >= 0) ? '.mp4' : '.webm'; const blob = Utilities.newBlob(Utilities.base64Decode(b64), mimeType, (maVanDon || 'VD') + '_' + loai + '_' + Date.now() + ext); const folder = DriveApp.getFolderById(DRIVE_FOLDER_ID); const file = folder.createFile(blob); file.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW); return 'https://drive.google.com/file/d/' + file.getId() + '/view'; } function jsonResponse(obj) { return ContentService .createTextOutput(JSON.stringify(obj)) .setMimeType(ContentService.MimeType.JSON); }
